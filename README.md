# 筆文字メーカー

文字を入れるだけで、筆で書いたような画像が作れる無料ツールです。
スマホでもパソコンでも、ブラウザだけで使えます。登録もいりません。

**▶ 使ってみる：https://hidenorimiyatake8-hash.github.io/fudemoji-maker/**

## できること

- 縦書き・横書き
- 紙の形（縦長・正方形・横長）
- 書体6種類（力強い筆、楷書、行書、手書き風など）
- 墨の色（墨・薄墨・朱・藍・金）
- かすれ・にじみの強さ
- 和紙の背景、白、透明
- 落款（ハンコ）を4文字まで
- PNG画像で保存
